## 它是什么？

VibeRemote 让你用手机（或任何带浏览器的设备）**通过局域网直接遥控电脑**：

- 🎯 **四向点击轮 + 中心键**：上下左右任意绑定键盘按键或组合快捷键（如 `Alt+Tab` 应用切换），中心键=鼠标左键
- 🖱️ **旋轮滑动**：在轮环上滑动 = 移动鼠标；双指滑动 = 滚动页面
- 🎤 **语音输入**：点输入框 → 用手机自带的输入法说话 → 输入法回车**自动发送**到电脑当前光标 + 回车
- 📋 **最近发送 + 重发**：发送记录本地持久化，没发成功的点「↻ 重发」即可
- ⚙️ **可折叠设置**：鼠标灵敏度三档（精/中/快）、四向键自定义绑定
- 🎨 **科技感 UI**：iPod 经典四向轮 + 霓虹蓝紫渐变 + 玻璃拟态 + 实时动态波形

> 💡 **Vibe coding 场景**：对着 AI 编程助手（Codex / Claude Code / 任意输入框）说话，把想法快速塞进代码框——手机就是你的"免手遥控器"。

## 快速开始（Windows）

1. 下载或克隆本项目
2. 双击 **`启动VibeRemote.bat`**（自动检查依赖，首次运行自动安装）
3. 电脑浏览器会自动弹出二维码
4. **手机扫码**（或在手机浏览器输入 `http://电脑IP:8081/`）
5. 开用！

停止服务：双击 **`停止VibeRemote.bat`**。

## 使用指南

```
┌──────────────────────────────┐
│ 展示区：连接状态 / 最近发送    │
│            (可滚动，点↻重发)   │
├──────────────────────────────┤
│ 输入条：点一下 → 手机输入法    │
│   说话 → 回车 = 自动发送       │
├──────────────────────────────┤
│ 控制轮：内圈点按=按键          │
│   外环滑动=鼠标 · 双指=滚动    │
│   ⚙ 左下角=设置               │
└──────────────────────────────┘
```

| 操作 | 效果 |
|---|---|
| 点 ▲▼◀▶ | 触发各自绑定的按键/组合键（默认：上下=方向键、左=退格、右=Alt+Tab） |
| 点中心键 | 鼠标左键点击 |
| 轮环上滑动 | 移动鼠标指针 |
| 双指滑动 | 滚动 |
| 点输入条 · 说话 · 输入法回车 | 文字发送到电脑 + 回车 |
| 长按方向键 | 进入设置页绑定该方向键（或点 ⚙ → 四向键绑定） |
| 点最近发送里的 ↻ | 重新发送该条文字 |

## 工作原理

```
手机浏览器 (单页 index.html)              Windows 电脑 (server.py)
┌────────────────────┐   WebSocket   ┌──────────────────────────┐
│ 四向轮 / 滑环 / 输入  │ ────────────► │ · 鼠标注入 (pynput)        │
│                    │ ◄──────────── │ · 键盘/组合键注入           │
│                    │   状态/日志回执  │ · 文本注入 (剪贴板+Ctrl+V)  │
└────────────────────┘              └──────────────────────────┘
                                            │ 注入到光标位置
                                            ▼
                             Codex / Claude Code / 任意输入框
```

- **纯局域网传输**：所有数据在你家/办公室的 Wi-Fi 内，不经过任何云端服务器，隐私安全
- **文字流语音**：语音识别由你的手机输入法完成，电脑只负责接收**文字**并注入，链路最短最稳

## 技术栈

| 层 | 技术 |
|---|---|
| PC 端 | Python 3 · `websockets` · `pynput` · `ctypes`(剪贴板) · qrcode |
| 手机端 | 单文件 HTML/CSS/JS（无框架、零依赖） |
| 传输 | 局域网 WebSocket |

---

## 目录结构

```
viberemote/
├── server.py            # PC 端服务：WebSocket + 鼠标/键盘/文本注入 + 静态网页
├── index.html           # 手机端单文件网页（所有 UI 与交互）
├── 启动VibeRemote.bat     # Windows 一键启动（自动装依赖、后台运行）
├── 停止VibeRemote.bat     # 停止服务
├── stop.ps1             # 停止脚本的 PowerShell 实现
└── requirements.txt     # Python 依赖
```

## 手动运行

```bash
pip install websockets pynput qrcode
python server.py
```

然后手机浏览器访问：`http://<你的电脑IP>:8081/`
