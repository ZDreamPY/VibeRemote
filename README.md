## 它是什么？

VibeRemote 让你用手机（或任何带浏览器的设备）**通过局域网直接遥控电脑**：

- 🎯 **四向点击轮 + 中心键**：每个键都有**单击 + 双击**两个独立自定义槽位（如：右键单击=`Alt+Tab`、右键双击=`Win+Tab` 应用切换；中心键单击=鼠标左键、双击=鼠标右键）
- 🖱️ **旋轮滑动**：在轮环上滑动 = 移动鼠标（外环有跟手旋转动效），双指滑动 = 滚动页面
- 🎤 **语音输入**：点输入框 → 用手机自带的输入法说话 → 输入法回车**自动发送**到电脑当前光标 + 回车
- 📋 **最近发送 + 重发**：发送记录本地持久化（刷新不丢），没发成功的点「↻ 重发」即可
- ⚙️ **可折叠设置**：鼠标灵敏度（精基准 +/− 微调，按自己手感调）、四向键/中心键单击+双击自定义绑定、主题切换
- 🎨 **4 套主题皮肤**：夜霓虹（蓝紫）/ 赛博星云（青品红）/ 银幕极简（浅色）/ 极客模式（黑+数码绿），一键切换
- 🔒 **配对码保护**：首次连接需输入配对 PIN，防止局域网内其他设备遥控你的电脑

> 💡 **Vibe coding 场景**：对着 AI 编程助手（Codex / Claude Code / 任意输入框）说话，把想法快速塞进代码框——手机就是你的"免手遥控器"。

## 快速开始（Windows）

1. 下载或克隆本项目
2. 双击 **`启动VibeRemote.bat`**（自动检查依赖，首次运行自动安装；若已打包可自动启动 `dist\VibeRemote.exe`）
3. 电脑浏览器会自动弹出**配对页**（二维码 + 配对 PIN）
4. **手机扫码**（或在手机浏览器输入 `http://电脑IP:8081/`）→ 首次输入配对 PIN，之后自动记住
5. 开用！

停止服务：双击 **`停止VibeRemote.bat`**。

> 🔒 **配对 PIN** 生成后保存在 `pin.txt`，重启服务保持不变（首次连接输入一次即记住）。如担心泄露，删除 `pin.txt` 重启即可重新生成。

## 使用指南

```
┌──────────────────────────────┐
│ 展示区：连接状态 / 最近发送    │
│            (可滚动，点↻重发)   │
├──────────────────────────────┤
│ 输入条：点一下 → 手机输入法    │
│   说话 → 回车 = 自动发送       │
├──────────────────────────────┤
│ 控制轮：内圈点按=按键          │
│   外环滑动=鼠标 · 双指=滚动    │
│   ⚙ 左下角=设置               │
└──────────────────────────────┘
```

| 操作 | 效果 |
|---|---|
| 点 ▲▼◀▶ | 触发各自绑定的**单击**功能（默认：上下=方向键、左=退格、右=Alt+Tab） |
| 快速连点 ▲▼◀▶ 两下 | 触发该键的**双击**功能（默认：右键双击=Win+Tab，其余键双击=不生效） |
| 点中心键 | 鼠标左键点击 |
| 快速连点中心键两下 | 鼠标右键点击 |
| 轮环上滑动 | 移动鼠标指针（外环有跟手旋转动效） |
| 双指滑动 | 滚动 |
| 点输入条 · 说话 · 输入法回车 | 文字发送到电脑 + 回车 |
| 点 ⚙ 左下角齿轮 | 设置面板：灵敏度精基准 +/− 微调 / 单击+双击绑定 / 主题切换 |
| 点最近发送里的 ↻ | 重新发送该条文字 |

## 工作原理

```
手机浏览器 (单页 index.html)              Windows 电脑 (server.py)
┌────────────────────┐   WebSocket   ┌──────────────────────────┐
│ 四向轮 / 滑环 / 输入  │ ────────────► │ · 鼠标注入 (pynput)        │
│                    │ ◄──────────── │ · 键盘/组合键注入           │
│                    │   状态/日志回执  │ · 文本注入 (剪贴板+Ctrl+V)  │
└────────────────────┘              └──────────────────────────┘
                                            │ 注入到光标位置
                                            ▼
                             Codex / Claude Code / 任意输入框
```

- **纯局域网传输**：所有数据在你家/办公室的 Wi-Fi 内，不经过任何云端服务器，隐私安全
- **文字流语音**：语音识别由你的手机输入法完成，电脑只负责接收**文字**并注入，链路最短最稳

## 技术栈

| 层 | 技术 |
|---|---|
| PC 端 | Python 3 · `websockets` · `pynput` · `ctypes`(剪贴板) · qrcode |
| 手机端 | 单文件 HTML/CSS/JS（无框架、零依赖） |
| 传输 | 局域网 WebSocket（配对 PIN 鉴权） |
| 打包 | PyInstaller（可发布独立 exe，免装 Python） |

---

## 目录结构

```
viberemote/
├── server.py            # PC 端服务：WebSocket(含配对鉴权) + 鼠标/键盘/文本注入 + 静态网页
├── index.html           # 手机端单文件网页（所有 UI 与交互）
├── 启动VibeRemote.bat     # Windows 一键启动（自动装依赖/自动启动打包exe、后台运行）
├── 停止VibeRemote.bat     # 停止服务
├── stop.ps1             # 停止脚本的 PowerShell 实现
├── build_exe.bat        # 一键打包为独立 exe（PyInstaller，免装 Python 即可运行）
├── requirements.txt     # Python 依赖
├── pin.txt              # 配对 PIN（首次启动自动生成）
└── dist/VibeRemote.exe  # 打包产物（build_exe.bat 生成）
```

## 手动运行

```bash
pip install websockets pynput qrcode
python server.py
```

然后手机浏览器访问：`http://<你的电脑IP>:8081/`
